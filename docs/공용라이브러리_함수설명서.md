# 공용 라이브러리 함수 설명서

> 작성일 2026-11-22 · 함수 목록·인자·동작은 이 저장소 `addins/_common/*.bas`, `addins/_client/*.bas`, `addins/clockout-vendor-*/`의 **실제 소스**에서 옮겼다. 소스와 다르면 소스가 이긴다. 소스를 고치면 이 문서도 같은 PR에서 고친다.
> 이 문서는 엑셀 추가기능 하위 프로그램에 붙는 VBA 기능 모듈을 만드는 사람(AI 포함)이 읽는다. 제작 기준 전체는 `기능모듈_제작기준_엑셀VBA.md`.
> **확인 범위**: 소스를 읽어 정리했고 Excel에서 다시 실행해 보지는 않았다. 소스 주석에 적힌 시험 결과(Windows Excel에서 `Test_*` 통과)를 그대로 믿지 말고, 새 기능 모듈을 만들 때 직접 컴파일·시험한다.

## 1. 왜 통합 라이브러리인가
기능 모듈마다 설정 읽기, 선택 범위 검사, 화면 갱신 끄고 켜기, 안내 창, 파일 고르기를 새로 짜면 같은 버그가 기능 모듈 수만큼 생기고 고칠 곳도 그만큼 늘어난다. 그래서 **한 번 짜서 공용 라이브러리에 두고, 모든 기능 모듈이 불러 쓴다.** 규칙은 둘이다.
1. **새로 짜기 전에 이 문서에서 먼저 찾는다.** 비슷한 함수가 있으면 그것을 쓴다.
2. 없으면 기능 모듈 안에 만들지 말고 **라이브러리에 더해 달라고 제안**한다(제작 기준 4장).

## 2. 구성
| 라이브러리 | id | 판 | 내용 | 진입점 |
|---|---|---|---|---|
| 칼퇴 공용 라이브러리 | `clockout-lib` | 0.1.001 | 이 저장소가 직접 만든 도우미 모음. 이 문서 4장 | `CoLib_Api` |
| 외부 라이브러리 묶음 4개 | `clockout-vendor-data`·`-text`·`-array`·`-sys` | 각 0.1.000 | 허용형 라이선스(MIT) 외부 공개 VBA를 **고치지 않고** 컴파일한 것. 이 문서 5장 | `CoVendor_Api` |

- 둘 다 독립 `.xlam`이다. 기능 모듈은 소스를 복사해 넣지 않고 설치된 라이브러리를 부른다. 라이브러리는 카탈로그에서 `category: "라이브러리"`로 받는다.
- 방향은 **기능 모듈 → 공용 라이브러리** 한쪽이다. 라이브러리는 기능 모듈에 기대지 않고, 외부 묶음끼리도 서로 부르지 않으며 `clockout-lib`는 외부 묶음을 참조하지 않는다.
- 모든 `Co` 모듈은 `Option Private Module`이라 Alt+F8 매크로 목록과 시트 함수 목록에 보이지 않는다. 다른 통합 문서에서는 아래 진입점 개체로만 부를 수 있다.

## 3. 부르는 방법

### 3-1. 독립 라이브러리를 부르는 방법 (기본)
1. 선언 `<id>.clockout.json`의 `dependencies`에 라이브러리를 적는다.
   ```json
   "dependencies": [{"id": "clockout-lib", "min_version": "0.1.001", "reason": "설정 읽기와 안내 창"}]
   ```
   빌드(`tools/build_addin.ps1`)가 이를 보고 연결부 `CoLibClient.bas`(외부 묶음이면 `CoVendorClient.bas`)를 기능 모듈 `.xlam`에 자동으로 넣는다. **직접 넣거나 고치지 않는다.**
2. 코드에서 진입점 개체를 한 번 받는다.
   ```vb
   Private Const ADDIN_NAME As String = "십자 음영"
   Private Const MIN_LIB As String = "0.1.001"        ' 선언의 min_version과 같게

   Private Function Api() As Object
       Set Api = CoLibClient_Api(MIN_LIB, ADDIN_NAME)  ' 없거나 판이 낮으면 안내 창을 띄우고 Nothing
   End Function

   Public Sub MyAddin_Run()
       Dim lib As Object, ws As Worksheet, rng As Range, why As String
       Set lib = Api(): If lib Is Nothing Then Exit Sub
       If Not lib.CoRange_GetSelection(ws, rng, why) Then lib.CoGuard_Notice why: Exit Sub
       ' ...
   End Sub
   ```
3. 이후 `lib.<함수 이름>(...)`으로 부른다(**늦은 바인딩**, `Dim lib As Object`). 함수 이름과 인자는 4장의 `Co…` 함수와 같다.
- `CoLibClient_Api(minVersion, addinName, [quiet])`: 라이브러리가 켜져 있고 `CoLib_Version`이 `minVersion` 이상이면 `CoLibApi` 개체를 돌려주고, 아니면 안내 창(칼퇴에서 받아 설치하라는 안내)을 띄운 뒤 `Nothing`. `quiet:=True`면 안내 창 없이 `Nothing`(이벤트처럼 자주 불리는 곳에서 쓴다).
- 내부 동작: `Application.Run("'clockout-lib.xlam'!CoLib_Api")`로 개체를 얻는다. 직접 쓰려면 같은 식으로 `Application.Run("'clockout-lib.xlam'!CoLib_Version")`(판 글 `"0.1.001"`)도 부를 수 있다. 연결부를 쓰는 것이 안전하다.
- **시작 때 부를 때 주의**: 라이브러리가 아직 안 켜졌을 수 있다. `Workbook_Open`에서 바로 부르지 말고 `Application.OnTime Now, "'" & ThisWorkbook.Name & "'!시작Sub"`로 조금 뒤에 실행한다(`ThisWorkbook_코드.txt` 참고).
- 개체는 한 번 얻어 모듈 변수에 두고 다시 써도 된다.

### 3-2. 진입점 개체로 부를 때 4장과 달라지는 점
같은 이름의 메서드지만 COM 개체 경계를 넘을 수 없는 것은 모양이 바뀐다.

| 함수 | 4장(직접 호출) | 진입점 개체(`lib.`) |
|---|---|---|
| `CoGuard_Begin` / `CoGuard_End` | 상태 값(`CoAppState`)을 돌려주고 받는다 | **`Long` 토큰**을 돌려주고 `CoGuard_End 토큰`으로 되돌린다. 상태는 개체가 보관. 모르는 토큰이나 이미 되돌린 토큰은 아무것도 안 한다 |
| `CoFitMath_CalcBox` | `CoFitBox` 구조체 | **`Variant` 배열** `(0:left, 1:top, 2:width, 3:height)`. 맞출 수 없으면 `Empty` |
| `CoSetting_Choice` | `ParamArray` | 같은 모양으로 부르면 된다(`lib.CoSetting_Choice(id, "align", "가운데", "가운데", "왼쪽 위")`) |
| 상수 `CO_*` | 상수 | 읽기 속성: `MsgTitle`, `FilterAll`, `FilterPictures`, `FilterExcel`, `FilterCsv`, `MmToPtFactor` |
| `ByRef` 인자(`ws`, `rng`, `reason`, `result` 등) | `ByRef` | 그대로 통한다(`Double`·`Date`·`String`·개체 모두 소스의 `Test_CoLibApi`가 확인) |
| `CoLib_Version`, `CoLib_Api` | 해당 없음 | 진입점 모듈 `CoLibEntry`에만 있다 |

### 3-3. 예전 방식 (선언에 `bundled: true`)
라이브러리 `.bas`를 기능 모듈에 직접 가져와 함께 컴파일하면 `lib.` 없이 `CoRange_GetSelection(...)`처럼 바로 부른다(`CoGuard_Begin`은 `CoAppState`를 돌려준다). 이때 `dependencies`에 `"bundled": true`를 적는다. 새 기능 모듈은 독립 라이브러리 방식을 쓴다(단축키 등록부 `CoKey`가 기능 모듈 사이에 공유되지 않는 등 단점이 있다).

### 3-4. 뼈대
```vb
Public Sub MyAddin_Run()
    Dim lib As Object, tok As Long, msg As String, why As String
    Dim ws As Worksheet, rng As Range, margin As Double

    Set lib = CoLibClient_Api(MIN_LIB, ADDIN_NAME): If lib Is Nothing Then Exit Sub
    If Not lib.CoRange_GetSelection(ws, rng, why) Then lib.CoGuard_Notice why: Exit Sub
    If Not lib.CoRange_CanEdit(rng) Then lib.CoGuard_Notice "보호된 셀이 있습니다.": Exit Sub
    margin = lib.CoSetting_Number(ADDIN_ID, "margin", 1#, 0, 20)   ' 선언의 default·min·max와 같게

    tok = lib.CoGuard_Begin()
    On Error GoTo EH
    ' ... 작업 ...
    lib.CoGuard_End tok
    Exit Sub
EH:
    msg = lib.CoGuard_ErrText("작업 중")   ' 맨 먼저: 다음 줄들이 Err를 지운다
    lib.CoGuard_End tok
    lib.CoGuard_Notice msg
End Sub
```

## 4. 공용 라이브러리 `clockout-lib` 함수 목록

이름 규칙: 모듈 `Co<분야>`, 함수 `Co<분야>_<동사·명사>`, 상수 `CO_` 대문자. 검사 함수는 안내 창을 직접 띄우지 않고 **`reason`(이유 글)을 돌려주며**, 띄울지는 부르는 쪽이 정한다. **실패해도 오류를 밖으로 던지지 않고** `False`·`""`·기본값을 돌려준다.

| 모듈 | 분야 | 순수 계산(Excel 없이 시험) |
|---|---|---|
| `ClockOutSettings` | 설정 읽기 표준 함수 | |
| `CoSetting` | 설정 읽기 한 줄로 | |
| `CoGuard` | 실행 상태 가드, 안내 창 | |
| `CoRange` | 시트·선택 범위 | |
| `CoShape` | 사진·도형 | |
| `CoFitMath` | 칸에 맞출 위치·크기 계산 | ○ |
| `CoFile` | 파일·폴더 | |
| `CoText` | 글자·경로·날짜 | ○ |
| `CoNum` | 숫자·단위·금액 | ○ |
| `CoKey` | 단축키 등록부 | ○ (일부) |

아래 예제는 진입점 개체 `lib`(3장)로 부르는 모양이다.

### 4-1. 설정 읽기: `ClockOutSettings`, `CoSetting`
칼퇴 설정창에서 사용자가 바꾼 값은 `%APPDATA%\ClockOut\settings\<기능 모듈 id>.json`(평평한 JSON)에 저장된다. 이 파일은 읽기 전용으로만 읽는다. **파일·키가 없거나 깨졌거나 형이 안 맞으면 항상 기본값**을 돌려주고 오류를 던지지 않는다. 값의 `default`·`min`·`max`·`options`는 선언 `params`와 같게 적는다.

| 함수 | 인자 | 반환 | 동작 |
|---|---|---|---|
| `ClockOut_GetSetting` | `addinId`, `key`, `defaultValue As Variant` | `Variant` | 표준 읽기. **기본값의 형이 곧 돌려받는 형**(Double·Long→숫자, Boolean→참거짓, String→글자). 보통은 아래 `CoSetting_*`를 쓴다 |
| `CoSetting_Number` | `addinId`, `key`, `defaultValue As Double`, [`lo`], [`hi`] | `Double` | 숫자 설정. `lo`·`hi`를 주면 그 안으로 제한 |
| `CoSetting_MmAsPt` | `addinId`, `key`, `defaultMm As Double`, [`loMm`], [`hiMm`] | `Double` | mm로 선언한 설정을 pt로 읽는다(도형 크기·위치는 pt) |
| `CoSetting_Bool` | `addinId`, `key`, `defaultValue As Boolean` | `Boolean` | 참거짓 설정 |
| `CoSetting_Text` | `addinId`, `key`, `defaultValue As String`, [`trimIt=True`] | `String` | 글자 설정. 기본은 앞뒤 공백을 지운다 |
| `CoSetting_Choice` | `addinId`, `key`, `defaultValue As String`, `options…` | `String` | 선택지 설정. 읽은 값이 `options` 중 하나와 **정확히 같을 때만** 돌려주고 아니면 기본값. `options`를 안 주면 읽은 값 그대로 |

```vb
Private Const ADDIN_ID As String = "image-fit"                 ' 선언의 id와 같게
mm   = lib.CoSetting_Number(ADDIN_ID, "margin", 0.8, 0, 20)    ' 0~20으로 제한
pt   = lib.CoSetting_MmAsPt(ADDIN_ID, "margin", 0.8, 0, 20)
n    = CLng(lib.CoSetting_Number(ADDIN_ID, "count", 3, 1, 99))
keep = lib.CoSetting_Bool(ADDIN_ID, "keepRatio", True)
al   = lib.CoSetting_Choice(ADDIN_ID, "align", "가운데", "가운데", "왼쪽 위")
```
**기능 모듈 파일 안에는 사용자 값을 저장하지 않는다.** 쓰기는 칼퇴만 한다.

### 4-2. 실행 상태 가드와 안내 창: `CoGuard`
매크로가 화면 갱신·이벤트·계산 방식을 바꿨다가 오류가 나도 **항상 원래대로** 되돌린다.

| 함수 | 인자 | 반환 | 동작 |
|---|---|---|---|
| `CoGuard_Begin` | [`noScreen=True`], [`noEvents=False`], [`manualCalc=False`], [`noAlerts=False`] | 상태(진입점은 `Long` 토큰) | 지금 상태(화면 갱신·이벤트·경고창·상태 표시줄·커서·계산 방식)를 저장하고, 인자로 고른 것만 끈다. 계산 방식은 열린 통합 문서가 없으면 저장하지 않는다 |
| `CoGuard_End` | 상태(토큰) | 없음 | 저장한 상태로 되돌린다. **두 번 불러도 안전**(두 번째는 아무것도 안 함) |
| `CoGuard_Status` | `text` | 없음 | 상태 표시줄에 진행 상황을 보인다. `CoGuard_End`가 원래대로 돌려놓는다 |
| `CoGuard_ErrText` | [`context="작업 중"`] | `String` | 오류 안내 글. **오류 처리부 맨 처음에** 불러야 `Err` 내용이 남아 있다(이 함수는 `Err`를 지우지 않는다) |
| `CoGuard_Notice` | `msg`, [`title`] | 없음 | 알림 창(경고 모양) |
| `CoGuard_Info` | `msg`, [`title`] | 없음 | 알림 창(정보 모양) |
| `CoGuard_Ask` | `msg`, [`title`] | `Boolean` | 예/아니오. **기본 단추는 "아니오"**(실수로 Enter를 눌러도 진행하지 않게). 지우기·덮어쓰기 확인에 쓴다 |
| `CoGuard_AskText` | `msg`, `ByRef result`, [`title`], [`defaultText`] | `Boolean` | 글자 입력창. 확인이면 `True`와 입력한 글자(빈 글자일 수 있음), 취소면 `False`와 `""`. 입력이 화면에 그대로 보이므로 암호 입력에는 쓰지 않는다 |
| 상수 `CO_MSG_TITLE` | | `"칼퇴"` | 창 제목(진입점: `MsgTitle`) |

```vb
tok = lib.CoGuard_Begin()                       ' 화면 갱신 끔(기본)
tok = lib.CoGuard_Begin(True, True, True)       ' 화면·이벤트·자동 계산도 끔
On Error GoTo EH
' ... 작업 ...
lib.CoGuard_End tok
Exit Sub
EH:
msg = lib.CoGuard_ErrText("사진을 넣는 중")      ' 반드시 맨 먼저
lib.CoGuard_End tok
lib.CoGuard_Notice msg
If lib.CoGuard_Ask("선택한 칸의 값을 지웁니다. 진행할까요?") Then ...
If lib.CoGuard_AskText("새 이름을 넣으세요", txt, , "기본값") Then ...
```

### 4-3. 시트·선택 범위: `CoRange`
| 함수 | 인자 | 반환 | 동작 |
|---|---|---|---|
| `CoRange_ActiveWorksheet` | `ByRef ws`, `ByRef reason` | `Boolean` | 활성 시트가 워크시트인지 확인하고 `ws`를 채운다. 아니면 `reason` |
| `CoRange_GetSelection` | `ByRef ws`, `ByRef rng`, `ByRef reason`, [`allowMulti=False`], [`allowWhole=False`] | `Boolean` | 선택한 셀 범위를 안전하게 얻는다. `allowMulti=False`면 떨어진 여러 영역 중 첫 덩어리만. `allowWhole=False`면 행·열 전체 선택을 막는다(수백만 칸을 도는 사고 방지). 실패하면 `reason`에 이유 |
| `CoRange_IsWholeRowOrCol` | `rng` | `Boolean` | 어느 한 덩어리라도 행 전체나 열 전체면 `True` |
| `CoRange_IsVisible` | `rng` | `Boolean` | 숨긴 행·열이 아니고 크기가 있으면 `True`(사진·도형을 놓을 수 있는 칸) |
| `CoRange_FirstCellArea` | `rng` | `Range` | 첫 칸이 병합 셀이면 병합 영역 전체, 아니면 그 칸 |
| `CoRange_HasMerged` | `rng` | `Boolean` | 병합 셀이 하나라도 있으면 `True` |
| `CoRange_IsProtected` | `ws`, [`forShapes=False`] | `Boolean` | 시트 보호 여부. `forShapes=True`면 개체(사진·도형) 보호를 본다 |
| `CoRange_CanEdit` | `rng` | `Boolean` | 값을 써도 되는 범위면 `True`(시트 보호 중이면 잠긴 칸이 하나도 없어야 함) |
| `CoRange_LastRow` | `ws`, [`col=0`] | `Long` | 값(수식 포함)이 있는 마지막 행. `col`을 주면 그 열만. 비어 있으면 0. **`col` 없이 부르면 `Find`를 쓰므로 사용자의 찾기 창 옵션이 바뀔 수 있다** |
| `CoRange_LastCol` | `ws`, [`row=0`] | `Long` | 값이 있는 마지막 열. `row`를 주면 그 행만. 비어 있으면 0 |
| `CoRange_Values2D` | `rng` | `Variant` | 범위 값을 **항상 2차원 배열(1부터)**로. 한 칸이어도 `(1,1)` 배열. 여러 덩어리면 첫 덩어리. 칸을 하나씩 읽고 쓰는 것보다 훨씬 빠르니, 다 고친 뒤 `rng.Value = 배열`로 한 번에 쓴다 |

```vb
If Not lib.CoRange_GetSelection(ws, rng, why) Then lib.CoGuard_Notice why: Exit Sub
If Not lib.CoRange_CanEdit(rng) Then lib.CoGuard_Notice "보호된 셀입니다.": Exit Sub
last = lib.CoRange_LastRow(ws, 1)               ' A열 마지막 값 행(없으면 0)
arr = lib.CoRange_Values2D(rng)                  ' 빠르게 읽고
' ... arr(i, j) 고치기 ...
rng.Value = arr                                  ' 한 번에 쓴다
```

## 5. 외부 라이브러리 묶음 `clockout-vendor-*`

외부 공개 VBA를 **원본 그대로** 층별 `.xlam` 4개로 컴파일한 것이다. 쓰는 묶음만 `dependencies`에 적으면 칼퇴가 그 묶음만 받아 켠다. 원본·커밋·라이선스는 `vendor/vba/SOURCES.md`, 라이선스 전문은 묶음 zip의 `licenses/`에 들어 있다.

### 5-1. 부르는 방법
선언에 `{"id": "clockout-vendor-data", "min_version": "0.1.000", "reason": "JSON 읽기·쓰기"}`를 적으면 빌드가 `CoVendorClient.bas`를 자동으로 넣는다.
```vb
Dim v As Object
Set v = CoVendorClient_Api("data", "0.1.000", "내 기능 모듈")   ' 묶음 이름: data·text·array·sys(또는 전체 id)
If v Is Nothing Then Exit Sub                                   ' 없거나 판이 낮으면 안내 후 Nothing
Set j = v.CoVendor_Json()
```
- `CoVendorClient_Api(pack, minVersion, addinName, [quiet=False])`: 묶음이 켜져 있고 판이 충분하면 진입점 개체, 아니면 안내 창 후 `Nothing`. 한 번 얻은 개체를 모듈 변수에 두고 다시 써도 된다.
- **묶음끼리는 서로 부르지 않는다.** stdVBA 개체(람다 등)를 다른 개체에 넘길 때는 **같은 묶음에서 만든 것**을 넘긴다. `clockout-lib`와 묶음은 이름이 겹치지 않아 한 기능 모듈에 같이 넣어도 된다(`CoLibClient`·`CoVendorClient`).
- 팩토리가 돌려주는 기본 개체는 `.Create(...)`로 새 개체를 만든다.

### 5-2. `clockout-vendor-data` (형식: JSON·사전·날짜) — VBA-JSON, VBA-Dictionary
| 메서드 | 돌려주는 것 |
|---|---|
| `CoVendor_Json()` | JSON·날짜 도구 `CoVendorJson` |
| `CoVendor_Dict()` | 빈 사전(VBA-Dictionary): `.Add 키, 값` / `.Exists(키)` / `d(키)` |

`CoVendorJson` 메서드: `.Parse(글)`(개체는 `Dictionary`, 배열은 `Collection`) · `.Stringify(값, [들여쓰기])` · `.ParseIso(글) As Date` · `.ToIso(날짜) As String` · `.ToUtc(날짜)` · `.FromUtc(날짜)`. 속성: `UseDoubleForLargeNumbers`, `AllowUnquotedKeys`, `EscapeSolidus`.
```vb
Set o = j.Parse("{""a"":[1,2],""b"":{""c"":""한글""}}")
x = o("a")(1)                         ' 1  (Collection은 1부터)
s = j.Stringify(o, 2)                  ' 들여쓰기 2칸으로 보기 좋게
```
VBA-UTC는 JsonConverter가 같은 이름의 날짜 함수를 이미 가지고 있어 묶음에서 뺐다. 날짜 변환은 `CoVendor_Json()`의 `.ParseIso`·`.ToIso`·`.ToUtc`·`.FromUtc`를 쓴다.

### 5-3. `clockout-vendor-text` (글자: 정규식·HTML) — stdVBA
| 메서드 | 돌려주는 것 |
|---|---|
| `CoVendor_Regex()` | 정규식 팩토리 `CoVendorRegex`: `.Create(패턴, [플래그], [stepsLimit=10000])`. 플래그 `"i"`(대소문자 무시) `"m"` `"s"` `"g"`. 결과 개체: `.Test(글)` `.Match(글)` `.MatchAll(글)` `.Replace(글, 바꿀 글)` |
| `CoVendor_Html()` | HTML 팩토리 `CoVendorHtml`: `.Create([태그="html"], [속성 짝 배열], [자체 닫힘])` · `.CreateFromHTML(글)` → `.CreateChild` `.CreateLiteral` `.ToString` |

```vb
Set rx = v.CoVendor_Regex().Create("(\d+)-(\d+)")
If rx.Test(s) Then s = rx.Replace(s, "$2-$1")
```
주의: stdRegex 최신판은 기본이 실험용 기계어 실행 모드라 Excel이 꺼진 일이 있어, `CoVendor_Regex().Create`는 **항상 순수 VBA 모드**로 만든다. 원본 파일은 고치지 않았다. stdHTML은 선택 인자를 빼고 부르면 오류가 나서 `CoVendor_Html()`이 빠진 인자를 채워 준다.

### 5-4. `clockout-vendor-array` (배열·람다) — VBA-Better-Array, stdVBA
| 메서드 | 돌려주는 것 |
|---|---|
| `CoVendor_Arr()` | 새 `BetterArray`: `.Push` `.Sort` `.Item(i)` `.Length` `.ToString` 등 |
| `CoVendor_StdArray()` | stdArray 팩토리: `.Create(값들)` · `.CreateFromArray(배열)` → `.Map` `.Filter` `.Join` |
| `CoVendor_Enum()` | stdEnumerator 팩토리: `.CreateFromArray(배열)` (지연 목록) |
| `CoVendor_Lambda()` | stdLambda 팩토리: `.Create("$1*2")` → `.Run(값)` |
| `CoVendor_Callback()` | stdCallback 팩토리: `.CreateFromModule(모듈, 함수)` |

```vb
Set a = v.CoVendor_Arr(): a.Push 3, 1, 2: a.Sort
Set dbl = v.CoVendor_Lambda().Create("$1*2")
s = v.CoVendor_StdArray().Create(1, 2, 3).Map(dbl).Join(",")    ' "2,4,6"  (람다는 같은 묶음에서 만든 것)
```

### 5-5. `clockout-vendor-sys` (시스템: 클립보드·레지스트리·창·프로세스) — stdVBA
| 메서드 | 돌려주는 것 |
|---|---|
| `CoVendor_Clipboard()` | stdClipboard: `.Text`(읽기·쓰기), `.Clear` 등 |
| `CoVendor_Perf()` | stdPerformance: `.CreateMeasure(이름)` `.CreateOptimiser()` |
| `CoVendor_Reg()` | stdReg: `.CreateFromKey("HKEY_CURRENT_USER\Software")` |
| `CoVendor_Process()` | stdProcess: `.Create(명령)` `.CreateFromProcessId(번호)` |
| `CoVendor_Window()` | stdWindow: `.CreateFromApplication()` `.CreateFromHwnd(창)` |
| `CoVendor_Acc()` | stdAcc: `.CreateFromApplication()` `.CreateFromPath(경로)` |
| `CoVendor_Image()` | stdImage: 이미지 만들기·그리기·파일로 내보내기 |
| `CoVendor_Com()` | stdCOM: `.Create(개체)` 저수준 COM 호출 |

시스템 접근(레지스트리·프로세스·창)은 사용자 PC에 영향을 줄 수 있으니 필요한 만큼만 쓰고, 지우기·바꾸기 전에는 확인을 받는다(제작 기준 6장).

묶음별 최신 사용법은 각 `addins/clockout-vendor-*/README.md`, 예제는 `addins/vendor-sample`(JSON 보기 좋게). 자세한 개체 메서드는 원본 프로젝트(VBA-JSON, stdVBA, VBA-Better-Array)의 문서를 본다.

## 7. 라이브러리에 함수를 더하려면
1. 이미 있는지 이 문서와 각 모듈 맨 위 주석을 먼저 본다. 비슷한 것이 있으면 인자를 늘려 고친다.
2. Office 개체를 안 쓰는 계산은 `CoText`·`CoNum`(또는 새 순수 모듈)에 두고 `Test_` 시험을 함께 더한다.
3. 모듈 맨 위 한국어 주석(사용법 줄)과 **이 문서**를 같이 고친다.
4. **이미 쓰는 공개 함수의 이름·인자 순서는 바꾸지 않는다**(다른 기능 모듈이 깨진다). 바꿔야 하면 새 이름으로 더한다.
5. 공개 함수를 더하거나 인자를 바꾸면 `python3 tools/gen_colibapi.py`로 `CoLibApi.cls`를 다시 만들어 같은 PR에 올린다(`--check`로 빠졌는지 확인). 사용자 정의 형이나 `ParamArray`를 쓰는 함수는 스크립트의 `SPECIAL`에 손으로 감싸기를 더한다.
6. 판을 올릴 때 `CoLibEntry.bas`의 `LIB_VERSION`과 `clockout-lib.clockout.json`의 `version`을 함께 고친다.
