# 문서 정리 도구 (book-clean)

시트 탭 **우클릭 > 칼퇴 문서 정리**. 공용 라이브러리(clockout-lib 0.1.001 이상) 필요.

| 도구 | 하는 일 |
|---|---|
| 마지막 셀 바로잡기 | 값 없이 서식만 남은 아래·오른쪽 빈 구역을 지워 Ctrl+End과 파일 크기를 정상화(보호·표·도형 있는 시트는 건너뜀) |
| 외부 링크·깨진 이름 정리 | 다른 파일 링크(값으로 굳히고 끊기)와 #REF! 이름을 찾아 삭제 |
| 인쇄 설정 일괄 복사 | 지금 시트의 용지·방향·여백·배율·머리글/바닥글을 다른 시트들에 복사 |

지우기 전에 목록·개수를 보여 주고 확인을 받으며, 실행 후에는 Ctrl+Z로 되돌릴 수 없으니 먼저 저장하세요. 설정은 칼퇴 설정창에서.
파일: `BookClean.bas`(메뉴·도우미) / `BookCleanLast.bas` / `BookCleanLinks.bas` / `BookCleanPage.bas`
