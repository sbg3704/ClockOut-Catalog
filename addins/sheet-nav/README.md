# 시트 사이드바 (`sheet-nav`)

엑셀 창 **왼쪽이나 오른쪽**에 시트 목록을 띄워 두고, 이름을 누르면 바로 그 시트로 이동한다. 시트가 많은 파일(견적서, 보고서 묶음)에서 아래 시트 탭을 좌우로 넘기지 않고 쓰려는 용도.

- 열기/닫기: 리본 단추 또는 설정에서 지정한 단축키(기본 없음), 매크로 `SheetNav_Toggle`
- 목록에서 시트 이름을 누르면 이동. 위 검색 칸에 글자를 넣으면 이름이 겹치는 시트만 남고, Enter는 첫 결과로 이동, 아래 화살표는 목록으로 이동
- "반대쪽" 단추로 왼쪽/오른쪽 바꾸기, "새로고침" 단추는 시트 이름을 바꾼 뒤 목록을 다시 읽을 때
- 시트를 추가하거나 다른 시트·통합 문서로 옮기면 목록이 저절로 바뀜(이름만 바꾼 경우는 새로고침)
- 설정(칼퇴 설정창): 붙일 쪽, 너비, 글자 크기, 숨김 시트 표시, 시작할 때 자동 열기, 단축키
- 필요: 공용 라이브러리 `clockout-lib` 0.1.001 이상(없으면 안내 창이 뜸)

## 규칙·한계
- VBA로는 엑셀 안에 붙는 진짜 작업창을 만들 수 없어, 엑셀 창 가장자리에 맞춘 **떠 있는 창**이다. 엑셀 창 크기를 바꾸면 다시 맞추고, 창을 손으로 옮기면 그 자리에 둔다.
- 숨김 시트는 설정을 켜야 "(숨김)"으로 보이고, 누르면 보이게 할지 묻는다. 아주 숨김(VeryHidden)은 보이지 않는다.
- 시트 보호·통합 문서 구조 보호와 상관없이 이동만 한다. 시트를 지우거나 고치지 않는다.
- 화면 `SheetNavForm.frm`, 이벤트 `SheetNavEvents.cls`, 목록·이동·자리 잡기 `SheetNav.bas`로 나눴다. 폼 컨트롤은 코드로 만들어 `.frx`가 필요 없다.
