# 보이는 칸만 복사·붙여넣기 (visible-copy)

필터나 숨긴 줄·열이 있는 표에서 생기는 복사·붙여넣기 문제를 막습니다. 공용 라이브러리(clockout-lib 0.1.001 이상) 필요.

- **문제**: 엑셀은 필터가 걸린 곳에 붙여넣으면 *숨은 줄에도 값을 덮어쓰고*, 손으로 숨긴 줄·열은 복사할 때 같이 딸려 옵니다.
- **보이는 칸만 복사** `Ctrl+Shift+C`: 숨은 줄·열을 뺀 보이는 칸만 복사해 둡니다(엑셀 클립보드도 보이는 칸만).
- **보이는 칸에만 붙여넣기** `Ctrl+Shift+V`: 붙일 첫 칸을 고르고 실행하면 목적지의 *보이는 줄·열에만* 차례로 넣습니다. 숨은 곳은 건드리지 않습니다.
- 우클릭 메뉴 "칼퇴 보이는 칸만 복사·붙여넣기"에도 있습니다. 단축키·붙여넣기 방식(전부/값만)은 설정에서.
- 붙여넣기는 확인 후 실행하며 Ctrl+Z로 되돌릴 수 없습니다. 목적지에 보이는 칸이 모자라면 하지 않습니다.
