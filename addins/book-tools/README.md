# 통합 문서 도구 (book-tools)

시트 탭 **우클릭 > 칼퇴 통합 문서 도구**. 공용 라이브러리(clockout-lib 0.1.001 이상) 필요. Ctrl로 시트 탭 여러 장을 함께 고르면 그 시트들에만 적용되는 도구가 있습니다.

| 도구 | 하는 일 |
|---|---|
| 숨은 시트 모두 보이기 | 숨은 시트를 한 번에 표시(이름 목록 확인 후). '완전히 숨김'은 설정을 켜야 포함 |
| 선택한 시트만 남기고 숨기기 | Ctrl로 고른 시트만 두고 나머지 보이는 시트를 숨김 |
| 시트 탭 이름순 정렬 | 1호, 2호, 10호 순서(자연 순서)로 탭 재배치 |
| 시트 이름 일괄 바꾸기 | 찾아 바꾸기(비우면 이름 앞에 붙이기), 31자·금지문자 처리, 겹치면 건너뜀 |
| 공유 전 정리 | 모든 보이는 시트를 A1·맨 위·배율 100%로 맞추고 첫 시트를 엶 |
| 원클릭 백업 | 원본 옆에 `이름_날짜_시각.확장자` 복사본(덮어쓰지 않음) |
| 선택한 시트를 PDF 하나로 | 고른 시트(안 골랐으면 보이는 시트 전부)를 PDF 파일 하나로 |
| 입력 칸 비우기 | 상수(숫자·글자)만 지우고 수식·서식 유지(양식 재사용) |

지우거나 바꾸는 도구는 확인 후 실행하며 Ctrl+Z로 되돌릴 수 없으니 먼저 저장하세요. 설정은 칼퇴 설정창에서.
파일: `BookTools.bas`(메뉴·도우미) / `BookSheets.bas` / `BookFiles.bas`
