# 빠른 셀 도구 (quick-tools)

셀 **우클릭 > 칼퇴 빠른 도구**. 공용 라이브러리(clockout-lib 0.1.001 이상) 필요.

| 도구 | 하는 일 |
|---|---|
| 값으로 고정 | 선택한 칸의 수식을 현재 값으로(수식 칸만) |
| IFERROR로 감싸기 | `=수식` -> `=IFERROR(수식,0)`. 이미 IFERROR인 칸·배열 수식은 건너뜀 |
| 부호 뒤집기 | 숫자 칸에 -1을 곱함(수식·글자·0 제외) |
| 앞뒤 글자 붙이기 | 각 칸 앞·뒤에 글자를 붙임(보이는 글자 그대로, 결과는 글자) |
| 병합 해제 -> 선택 영역 가운데 | 병합을 풀고 같은 범위를 '선택 영역의 가운데'로(정렬·복사가 덜 깨짐) |
| 텍스트 날짜를 날짜로 | "2026.11.08", "20261108" 등을 진짜 날짜로 |
| 조건으로 칸 선택 | 병합·오류·수식·잠금 해제·빈 칸·보이는 칸을 한꺼번에 선택(값은 안 바뀜) |

값을 바꾸는 도구는 "N칸이 바뀝니다" 확인 후 실행하며 Ctrl+Z로 되돌릴 수 없으니 먼저 저장하세요. 설정은 칼퇴 설정창에서.
파일: `QuickTools.bas`(메뉴·도우미) / `QuickEdit.bas` / `QuickMisc.bas`
