# 범위 도구 (range-tools)

셀 **우클릭 > 칼퇴 범위 도구**. 공용 라이브러리(clockout-lib 0.1.001 이상) 필요.

| 도구 | 하는 일 |
|---|---|
| 자연 정렬 | 1호, 2호, 10호 순서(숫자는 크기로)로 줄 단위 정렬. 서식·수식이 줄과 함께 이동, 병합 칸 있으면 안 함, 최대 5000줄 |
| 색깔별 합계 | 칸 색(또는 글자색)별 개수·합계를 창 또는 새 시트로. 읽기만 함, 직접 칠한 색만(조건부 서식 색은 제외) |
| 그룹별 시트로 쪼개기 | 활성 칸의 열 값별로 새 시트(제목+해당 줄)와 소계 시트를 만듦. 원본은 그대로 |

자연 정렬은 되돌릴 수 없으니 먼저 저장하세요. 설정은 칼퇴 설정창에서.
파일: `RangeTools.bas`(메뉴·도우미) / `RangeSort.bas` / `RangeColor.bas` / `RangeSplit.bas`
