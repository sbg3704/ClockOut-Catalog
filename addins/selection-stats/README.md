# 선택 요약 크게 보기 (`selection-stats`)

엑셀 아래 상태 표시줄의 **합계·평균·개수**를 큰 글자로, 떠 있는 작은 창에 보여 준다. 칸을 고를 때마다 바로 바뀐다.

- 열기/닫기: 리본 버튼 또는 설정에서 지정한 단축키(기본 없음), 매크로 `SelStats_Toggle`
- 설정(칼퇴 설정창): 숫자 글자 크기(12~80pt), 천 단위 쉼표, 숫자 개수·최소·최대 보기, 시작할 때 자동 열기, 단축키
- 필요: 공용 라이브러리 `clockout-lib` 0.1.001 이상(없으면 안내 창이 뜸)

## 규칙
- 개수는 비어 있지 않은 칸 수(상태 표시줄과 같다). 숨긴 줄(필터로 가려진 줄 포함)과 오류 칸은 세지 않는다.
- 선택이 아주 커도(시트 전체) "사용 중인 범위"와 겹치는 부분만 계산해 느려지지 않는다.
- 값 계산 `SelStatsCalc.bas`, 화면 `SelStatsForm.frm`, 이벤트 `SelStatsEvents.cls`로 나눠 두었다. 폼의 컨트롤은 코드로 만들어 `.frx`가 필요 없고, 빌드는 `.frm`에서 폼을 새로 만들어 코드를 넣는다.
