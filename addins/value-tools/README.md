# 값 정리 도구 (value-tools)

셀을 **우클릭 > 칼퇴 값 정리**에서 쓰는 작은 도구 7개입니다. 공용 라이브러리(clockout-lib 0.1.001 이상)가 필요합니다.

| 도구 | 하는 일 |
|---|---|
| 공백·숨은문자 정리 | 앞뒤·중복 공백, 줄바꿈 아닌 숨은 문자(NBSP, 제로폭 등) 제거 |
| 텍스트 숫자를 숫자로 | "1,200", "(500)", "300-", " 12 " 같은 글자를 숫자로. 00123 같은 코드는 기본으로 건드리지 않음 |
| 병합 해제 + 값 채우기 | 병합을 풀고 병합 칸 전체에 첫 칸 값을 채움 |
| 빈 칸을 위 값으로 채우기 | 열마다 빈 칸에 바로 위의 값을 채움 |
| 올림·절사·반올림 | 보이는 서식이 아니라 **실제 값**을 단위(1, 100, 1000, 0.01…)로 바꿈 |
| 한글 금액 | 12345 -> 일금 일만이천삼백사십오원정 (오른쪽 빈 칸 또는 같은 칸) |
| 두 열 다른 칸 선택 | 나란한 두 열(또는 Ctrl로 고른 두 열)을 줄 단위로 비교해 다른 줄만 선택 |

## 안전 규칙
- 값을 바꾸는 도구는 먼저 "N칸이 바뀝니다"를 알리고 확인을 받습니다.
- 수식 칸은 건드리지 않습니다(상수만). 보호된 시트의 잠긴 칸이 있으면 실행하지 않습니다.
- 실행 후에는 Ctrl+Z로 되돌릴 수 없습니다(VBA의 한계). 중요한 파일은 먼저 저장하세요.

## 설치(수동)
`build_addin.ps1 -Addin value-tools`로 만든 .xlam을 추가기능으로 켜고, ThisWorkbook 코드는 `ThisWorkbook_코드.txt`를 붙여 넣습니다(빌드 스크립트가 자동 처리).
설정은 칼퇴 설정창에서 바꿉니다(`value-tools.clockout.json`의 params).

## 파일
`ValueTools.bas`(메뉴·도우미) / `ValueFix.bas` / `ValueMath.bas` / `ValueCompare.bas`
