' 기능: 추가기능(.xlam)을 켤 때 단축키를 등록하고 끌 때 해제한다.
' 사용법: VBA 편집기에서 ThisWorkbook(현재_통합_문서)을 열어 아래 내용을 붙여 넣는다.
'         (ThisWorkbook은 .bas로 가져올 수 없어 텍스트로 둔다.)
' 의존: ImageFit.bas, ClockOutSettings.bas

Private Sub Workbook_Open()
    On Error Resume Next
    ImageFit_RegisterShortcuts
End Sub

Private Sub Workbook_AddinUninstall()
    On Error Resume Next
    ImageFit_UnregisterShortcuts
End Sub

Private Sub Workbook_BeforeClose(Cancel As Boolean)
    On Error Resume Next
    ImageFit_UnregisterShortcuts
End Sub
