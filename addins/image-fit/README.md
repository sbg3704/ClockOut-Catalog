# 사진 셀에 맞추기 (image-fit) — 칼퇴 예제 추가기능

> 앱 저장소(sbg3704/ClockOut)의 `addins/image-fit`에서 이 저장소로 옮겨 왔다(2026-11-08). 문서 속 `docs/02`·`docs/03`은 앱 저장소 기준이다.

원본 `사진매크로 시트.xlsm`의 매크로 2개(`insert_Pic`, `개체를_셀에맞춤`)를 칼퇴 기준(docs/02·03)으로 다시 짠 예제 추가기능이다.

## 파일
| 파일 | 역할 |
|---|---|
| `image-fit.clockout.json` | 설정 선언(여백·비율·정렬·범위·배치·단축키 7개) |
| `ImageFit.bas` | 매크로 3개 + 단축키 등록 + 이 추가기능만의 설정 묶기(약 200줄). 나머지는 공용 라이브러리를 쓴다 |
| `ThisWorkbook_코드.txt` | 열 때·닫을 때 단축키 등록(ThisWorkbook에 붙여 넣기) |
| `../_common/*.bas` | 공용 라이브러리(PR#10). 이 추가기능에 필요한 것: `ClockOutSettings`, `CoNum`, `CoSetting`, `CoGuard`, `CoRange`, `CoFile`, `CoText`, `CoFitMath`, `CoShape`. 규칙은 `../_common/README.md` |

## ? 설명 위치
앱 목록의 ? 툴팁은 선언 JSON의 `description`을 먼저 읽는다(결정: JSON 우선, 코드 주석 읽기는 나중에 같은 칸에 연결). 코드 맨 위 `'@desc` 줄은 그때를 위한 자리이며, 지금은 JSON과 같은 뜻으로 맞춰 둔다.

## 만드는 법 (.xlam)
1. `python3 tools/vba_encode.py out_vba` — 저장소 원본은 UTF-8인데 VBA 편집기는 CP949+CRLF만 바르게 읽으므로 변환본을 만든다.
2. 새 통합 문서에서 Alt+F11 > 파일 가져오기로 `out_vba`의 `.bas`(이 추가기능의 `ImageFit.bas`와 위 `_common` 9개)를 넣고, `ThisWorkbook_코드.txt`를 ThisWorkbook에 붙여 넣는다.
3. 직접 실행 창에서 `Test_CoFitMath`, `Test_CoText`, `Test_CoNum` 실행 → "모두 통과" 확인 후 `.xlam`으로 저장, `image-fit.clockout.json`을 옆에 둔다.

## 원본에서 바꾼 것 (예상한 오류와 처리)
| 원본의 문제 | 처리 |
|---|---|
| `If Pic = False`: 파일을 고르면 문자열과 불리언 비교로 형 불일치 오류 위험 | `VarType(pic) = vbBoolean`으로 취소 판정 |
| 붙여넣기를 먼저 하고 선택이 셀이면 그제야 종료 → 셀 내용이 덮어써짐 | 칸 확인 → 시트 보호 확인 → `Pictures.Paste`(사진 아니면 오류를 안내) 순서 |
| 빈 클립보드·사진 아닌 데이터 | 오류 대신 "붙일 사진이 없습니다" 안내 |
| 사진 비율 무시(찌그러짐) | `keepRatio`(기본 켬)로 칸 안에 비율대로 맞춤, 정렬 선택. 끄면 원본처럼 꽉 채움 |
| 여백 비대칭(왼쪽 위 +2.3, 크기 -4) | 사방 같은 여백(mm), 작은 칸은 짧은 변의 1/4로 제한 |
| 병합 셀 | 한 칸 선택 시 병합 영역 전체 기준 |
| 숨긴 행·열, 크기 0 | 안내 후 중단(사진 안 남김) |
| 행·열 전체 선택 | 안내 후 중단 |
| 떨어진 여러 영역 선택 | 첫 덩어리 기준 |
| 시트 보호 | 개체 보호면 안내(해제 후 재실행) |
| 차트 시트·통합 문서 없음 | 안내 |
| 깨진·미지원 사진, 없는 파일 | `AddPicture` 실패 안내, 반쯤 놓인 개체 삭제 |
| `ScreenUpdating`이 오류 시 꺼진 채 남음 | 이전 값 저장 후 오류 처리에서 항상 복구 |
| 줌 100% 강제 변경(불필요, 창 없으면 오류) | 제거(개체 좌표는 줌과 무관) |
| 이미 찌그러진 사진 | `FitSelected`가 원본 비율 복구 후 맞춤 |
| 회전된 개체 | 가로·세로 뒤섞임을 피해 건너뜀 |
| 숫자·단축키가 코드에 박힘 | 전부 설정 선언(JSON)으로 뺌, 못 읽으면 기본값 |

## 확인한 범위 / 못 한 것
- 클라우드(Linux)에서 작성: JSON 형식과 `tools/vba_encode.py` 변환만 확인. **VBA 컴파일·Excel 실행은 아직 못 했다.** Windows Excel에서 위 3단계와 실제 사진 넣기를 확인해야 한다.
- `Pictures.Paste`가 셀을 복사한 상태에서 어떻게 동작하는지(사진으로 붙는지 오류인지)는 실제 확인 전이다. 어느 쪽이든 셀 값은 건드리지 않는다.
- 사용자 폴더 이름이 한글이고 영문 Windows면 `Environ("APPDATA")` 경로가 깨질 수 있다. 그때는 기본값으로 동작한다.
