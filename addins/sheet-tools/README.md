# 시트 도구 (sheet-tools)

시트 탭을 **우클릭 > 칼퇴 시트 도구**에서 쓰는 도구 4개. 공용 라이브러리(clockout-lib 0.1.001 이상) 필요.

| 도구 | 하는 일 |
|---|---|
| 시트 목차 만들기 | 모든 시트를 링크로 나열한 "목차" 시트를 맨 앞에 만듦(상태·사용 범위 포함) |
| 목록으로 시트 만들기 | 선택한 칸의 글자를 이름으로 새 시트 생성(빈 시트 또는 현재 시트 복사). 중복·기존 이름은 건너뜀 |
| 시트별 파일로 내보내기 | 시트마다 .xlsx 파일로 저장(원본은 그대로, 기본은 수식을 값으로). 같은 이름 파일은 덮어쓰지 않음 |
| 폴더 파일 목록 만들기 | 폴더 안 파일 목록(이름·확장자·크기·수정일·경로)을 새 시트에, 이름 클릭으로 파일 열기 |

기존 시트를 지우거나 덮어쓰지 않습니다(목차 시트를 다시 만들 때만 확인 후 내용을 새로 씀). 설정은 칼퇴 설정창에서.
파일: `SheetTools.bas`(메뉴·도우미) / `SheetIndex.bas` / `SheetMake.bas` / `SheetExport.bas` / `FolderList.bas`
