# 십자 음영 (`cross-hair`)

선택한 칸의 **행과 열**을 표시해 큰 화면에서도 어느 칸인지 한눈에 보이게 한다.
선택한 칸은 진한 연두, 같은 행·열의 보조 칸은 아주 연한 연두 + 연한 선으로 구분한다.

- 켜고 끄기: **Ctrl+Shift+H** (설정에서 바꿈), 매크로 `CrossHair_Toggle`
- 설정(칼퇴 설정창): 표시 방식(선 / 선 + 연한 음영 / 음영만), 보조 줄 선·음영 색, 선택한 칸 색, 행·열 켜기, 시작할 때 자동 켜기, 단축키
- 필요: 공용 라이브러리 `clockout-lib` 0.1.001 이상(없으면 안내 창이 뜸)

## 원리
셀 값은 건드리지 않는다. 시트 전체에 **표시 전용 조건부 서식 규칙**을 걸고, 규칙 수식이 `CELL("row")`·`CELL("col")`(지금 선택한 칸)을 읽는다. 선택이 바뀔 때마다 그 시트만 다시 계산시켜 규칙이 새 위치를 읽게 한다. 끄거나 저장·닫기 직전에는 규칙을 지워 파일에 남지 않는다.

## 알아둘 점
- 음영(채우기)은 조건부 서식이라 반투명이 안 돼 칸의 원래 배경색을 덮는다. 그래서 기본 색을 아주 연하게 했고, "선"만 쓰면 덮지 않는다.
- 보호된 시트에는 걸 수 없다(건너뜀).
- 시트에 NOW·OFFSET·INDIRECT처럼 바뀔 때마다 다시 계산되는 수식이 매우 많으면 클릭할 때마다 그 계산이 다시 돈다. PC 시험(10만 줄 시트)에서 클릭당 추가 시간은 약 0.2~0.4ms였다.
- 조건부 서식을 거는 순간 엑셀의 되돌리기(Ctrl+Z) 기록이 지워질 수 있다(켤 때 한 번).
